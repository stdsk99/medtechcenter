# ศูนย์การเรียนรู้เทคโนโลยีทางการแพทย์

เว็บหลักที่รวมสื่อฝึกซ่อมเครื่องมือแพทย์ เปิดผ่าน GitHub Pages ที่ `https://stdsk99.github.io/medtechcenter/`

## ไฟล์

```
index.html      หน้าแรก
course.html     รายละเอียดวิชาและปุ่มลงทะเบียนเรียน (?c=pump หรือ ?c=incubator)
login.html      สมัครสมาชิก / เข้าสู่ระบบ
my.html         วิชาของฉัน: ความคืบหน้าและเกียรติบัตร
verify.html     ตรวจสอบเลขที่เกียรติบัตร
soon.html       หน้าชั่วคราวของหน้าที่ยังไม่ได้ทำ
css/site.css    หน้าตาเว็บ
js/config.js    ตั้งค่า: URL ของ Apps Script, ที่อยู่ของแอปฝึกซ่อม, ช่องทางติดต่อ
js/api.js       บัญชีผู้เรียนและการเชื่อมต่อ Apps Script (session ร่วม "mtc-session")
js/courses.js   ข้อมูลวิชา
js/site.js      แถบเมนู ส่วนท้าย และตัวอย่างเคสในหน้าแรก
```

## แอปที่เชื่อม

- Infusion Pump: `stdsk99/infusion-pump-trainer`
- ตู้อบทารก: `stdsk99/infant-incubator-trainer`

ย้ายไปโฮสต์อื่นได้โดยอัปโหลดไฟล์ทั้งหมด แล้วแก้ที่อยู่แอปใน `js/config.js`

## ระบบบัญชีและการลงทะเบียนเรียน

- หลังบ้านคือ Google Apps Script ตัวเดียวกับแอปฝึกซ่อม (`apps-script/Code.gs` ใน repo `infant-incubator-trainer`)
- ล็อกอินที่เว็บหลักครั้งเดียว แล้วเข้าแอปได้เลย เพราะทุก repo อยู่โดเมน `stdsk99.github.io` เดียวกัน
- เปิดแอปตรงๆ โดยยังไม่ล็อกอินหรือยังไม่ลงทะเบียนวิชา แอปจะพากลับมาที่หน้าวิชา
- ผู้เรียนเดิมที่เคยเรียนในแอป ระบบลงทะเบียนวิชาให้อัตโนมัติ (ดูแท็บ `enrollments` ใน Sheet)
